Browser presence

This setting checks only whether a DLMS page is still open. It does not monitor clicks, typing, scrolling, quiz progress, or inactivity.

Quiz sessions: This option does not save or resume an unfinished quiz. Closing a quiz page has the same in-page progress behavior as before.
