Restore is deliberately cautious.The uploaded ZIP is checked for archive integrity, traversal/symlink attacks, schema compatibility, duplicate paths, and expansion limits. DLMS also creates a pre-restore backup of the current data before applying the snapshot.
Portable design: runtime data is stored separately from the executable. A DLMS backup is intended to move that persistent data between compatible DLMS installations and provide a recovery point before destructive maintenance.
