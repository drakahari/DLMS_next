⚠️ Reset & Remove

Clear saved results, choose the narrowest reset that solves the problem, or permanently remove DLMS data. Scoped resets create safety backups; permanent removal does not.

Clear completed attempts and missed-question history without deleting quizzes.

This action cannot be undone unless you have a backup.Clearing history permanently removes saved attempts, attempt answers, and missed-question records. Quizzes remain in the Quiz Library.

Clear the answer evidence DLMS uses for mastery, recommendations, diagnostics, and scheduled review.

Reset DLMS to Fresh State

Remove active user/runtime data and return DLMS to a first-run state while preserving recovery backups.

Fresh-state reset removes essentially all active runtime/user data:
  • Quizzes, questions, generated quiz pages and quiz assets
  • Attempts, missed-question history, and database records
  • Study/Content Packs and Smart PDF source banks
  • Law Study runtime content and drafts
  • Appearance, parsing, and AI settings
Existing backup ZIPs are deliberately preserved. DLMS then recreates the empty/default folders and database it requires to keep running. The executable/application files are not removed.
×

Remove DLMS Data from This Computer

Permanently remove the entire DLMS-owned writable data directory, including backups, then shut DLMS down.

Permanent removal deletes all DLMS runtime data on this computer:
  • Quizzes, history, settings, Study/Content Packs, Smart PDF banks, drafts, assets, and caches
  • All safety and manual backup ZIPs stored inside the DLMS data directory
  • The DLMS application-data folder itself
The DLMS executable/source installation is NOT removed. Nothing outside the configured DLMS application-data directory is intentionally deleted. To use DLMS again, launch the executable/source installation and DLMS will create a new empty data directory.
This action has no automatic recovery backup.Any backup created inside the DLMS data directory would be deleted by this operation. Download or copy any backup you want to keep somewhere else before continuing.
Data directory that will be removed:{{ app_data_dir }}
Reset vs. removal: “Reset DLMS to Fresh State” preserves backup ZIPs and recreates the runtime structure so DLMS remains immediately usable. “Remove DLMS Data from This Computer” deletes the entire DLMS runtime-data directory, including backups, and shuts the application down. Neither action removes the executable/source installation.
