How filters and bulk actions work

Filters change which question cards are visible. Select All Visible selects only cards in the current filtered view; selections remain when you switch filters. Clear Selection clears selections across every filter.

Confirm Selected as Reviewed confirms only selected, included questions with a currently valid answer mode and complete correct-answer set. Use it only after comparing each selected draft with its source; questions that cannot be confirmed are listed and remain unconfirmed.

Mark Selected for Deletion turns on each selected card's Delete question setting. Keep Selected turns it back off. Nothing is committed until you choose Save Reviewed Question Bank.
