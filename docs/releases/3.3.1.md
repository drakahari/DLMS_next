## Server and data compatibility

Desktop Local bundles its application; Desktop Server uses the selected server.
For the full corrected feature set use server F or original S above. A 3.3.0 version
string is insufficient to identify later shared fixes: source 5e5fa245 contains some
but lacks the full certificate/Avery baseline. Older-client/new-server combinations
are not newly qualified. Maintain exact origins, explicit private-HTTP consent,
authentication boundaries and distinct Local/Server stores with no silent fallback.

Schema 12 / backup 1 / portablequiz 2 (legacy 1 imports) / pack 1 are unchanged. No new
migration is introduced. Never share a live directory between editions. Publishing
is not an installation/production update. Preserve a verified backup and previous
payload before a separately planned update; keep managed Fedora Desktop's existing
launcher/profile contract rather than substituting AppImage defaults.
