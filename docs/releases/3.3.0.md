# DLMS 3.3.0

DLMS 3.3.0 adds durable learning workflows, more control over study and
certification planning, and safer content transfer. The five native packages
below were built from frozen source commit
`af6766a8c59da513870014141c60aaa1edd1d232`.

## Highlights

- **Study and review:** Study sessions now retain first answers, corrections,
  assistance and completion across restarts. Study History, Exam History and
  resume controls make saved work easier to find. Study mistakes can create
  mixed quizzes using random draws or saved passes without repeats; eligible
  sources and remaining pass capacity are shown separately.
- **Planning:** Exam Plans combine selected folders with Learning Scope, study
  days and a saved calendar timezone. Mark for review provides focused practice
  and text-choice Anki export without clearing saved marks.
- **Certifications and training:** Track issuers, evidence, renewal history,
  deadlines, training time and credits separately. AI matching remains a manual
  copy/open/paste workflow, not an issuer approval or automatic submission.
- **Content fidelity:** Portable quiz bundle format 2 preserves choice order,
  labels, text and correct flags, including repeated values. Import review
  keeps incomplete content visible for repair without inventing answers.
- **Appearance:** The theme inventory now includes 26 palettes, including
  Ethereal. Dashboard, sidebar and Study views received focused spacing and
  navigation improvements. Purple & Gold remains the default.

## Fixes and hardening

Backup creation and restore validation received consistency and collision
handling fixes. Reduced-round matching Exams save their validated results.
Quiz repair, Study save retries and large Mix Questions filtering received
focused corrections. The frozen dependencies include patched pypdf and
Werkzeug versions and PDFium 5.14.0. These changes do not constitute a
security guarantee.

in one directory, `sha256sum --check SHA256SUMS.txt` verifies the complete set.

## Upgrading from public 3.2.2

**Back up your DLMS data before first starting 3.3.0**, and keep the backup
outside the live data directory. Public 3.2.2 uses database schema 3;
3.3.0 migrates a compatible profile to schema 12. An older application refuses
the upgraded database. Replacing the executable does not undo the migration.
Rollback requires the older application and a verified pre-upgrade backup in
a separate compatible data root; changes made after that backup will not be
present. Restore replaces a profile rather than merging records. The backup
archive format version remains 1, but its database content follows the schema
of the application that created it.

Portable quiz bundles exported by 3.3.0 use format 2. Older receivers reject
that format; 3.3.0 still imports supported format-1 bundles. Database schema
12 and portable format 2 were already present in the earlier `851db4d`
3.3.0 candidate, so there is no schema or portable-format transition between
that candidate and the frozen `af6766a8` build. The migration above describes
the change from the **public 3.2.2 release**.

See the [user manual](https://github.com/drakahari/DLMS_next/blob/v3.3.0/docs/user-manual/README.md)
for backup, restore and upgrade steps.

## Validation and limits

During the earlier candidate review, 3.3.0 was an **unreleased development target**.
Native build acceptance alone did not authorize publication. The
release PR, CI, tag and asset verification provide the separate publication
record.

All five native release builders passed their dependency, OCR probe, package
and smoke gates. Broader packaged PDF/image OCR, Study/Exam persistence and
exact backup/restore checks ran on Fedora with synthetic data. The additional
Ubuntu 24.04 packaged harness was canceled and is not counted as a pass.
Those Fedora checks do not establish equivalent end-to-end behavior on every
other platform or browser. Screen readers, forced colors, physical mobile
devices and cross-platform display scaling have not received complete
accessibility qualification. No signing or notarization is claimed.
