# DLMS 3.2.2 release notes

Status: source prepared for owner review; packages and publication require the
separate release-execution gates. The GitHub Releases page determines package
availability.

DLMS 3.2.2 is a focused maintenance and hardening release:

- Learning review planning reuses one immutable answer-event snapshot across
  its review, intelligence, and adaptive-study signals. This avoids repeated
  reads while preserving the existing selection and scoring rules.
- The browser UI uses repository-local SVG icons in place of Unicode, emoji,
  and font-dependent symbols. Sidebar feature icons use theme-aware accent
  families that align with their dashboard counterparts. This improves
  cross-platform consistency without redesigning navigation or changing data.
- Request error negotiation handles equal HTML/JSON preferences as HTML for
  page requests while preserving JSON responses for API routes. Temporary
  debug output was removed.

The four supported themes remain Light, Dark, Purple & Gold, and Maroon & Gold.
No dependency, data-format, or migration change is part of this release.
The optional [Omarchy companion plugin](https://github.com/drakahari/omarchy-dlms)
is maintained separately and is not included in DLMS packages or source.

Back up important data before upgrading. See the [user manual](../user-manual/README.md),
[source readiness review](3.2.2-READINESS.md), and
[release execution checklist](3.2.2-RELEASE-CHECKLIST.md).
