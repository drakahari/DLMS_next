## Corrections

- Certificate validation distinguishes supported PDFs that open with an empty
  user password from PDFs requiring an opening password. Only the empty password
  is attempted. Strict parsing, size/page/structure/active-content checks remain.
  Stored and downloaded original PDF bytes are preserved; View still renders an
  inert, bounded page preview. No original ISACA certificate has been tested.
- Pillow 13.0.0 and pypdf 6.21.4 address the verified advisory findings without a
  pypdf major-version migration. The locked AES provider is cryptography 50.0.2,
  cffi 2.1.1 and pycparser 3.12. The Linux producer's setuptools is 84.2.1.
- Runtime, build, test and Linux producer dependency audits run independently;
  an earlier audit finding no longer prevents the test audit from running.
- Firefox sorting waits for the submitted replacement document; Marked-sidebar
  checks wait for the shared navigation script. Deterministic held-request tests
  reproduce both old synchronization failures without sleeps or weaker checks.
- Candidate package names consistently use `3.3.2-RC1`, while application headers
  and About retain the display version `3.3.2 RC1`. Importlib collection preserves
  distinct same-named Mac/Windows tests instead of excluding either module.

## Compatibility and qualification

pack format 1 are unchanged; no migration is introduced. Use isolated synthetic
profiles for candidate checks. Local and Server data remain separate; Server
behavior is provided by the connected server, not changed by a client update.

Qualification results, exact hashes, source/notices and launch instructions are
external candidate companions. Source tests do not constitute native Save As,
physical printing or original-certificate acceptance. No other OS build, signing,
