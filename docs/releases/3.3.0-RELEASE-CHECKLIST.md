This records the frozen source and approved native-package inputs. The release
PR will record CI and merge state; the
[v3.3.0 release](https://github.com/drakahari/DLMS_next/releases/tag/v3.3.0)
will record tag and publication state.

- Frozen build source: `af6766a8c59da513870014141c60aaa1edd1d232` on
  `develop/3.3.0`.
- Main before the release merge: `4f28941c538596ab2ff45adaa44e6a503f870bcd`.

  `3a20d4e6f80260ddc0739d22f905751faa733036`, exactly the frozen build

  `af6766a8` use schema 12 and format 2; there is no transition between those
  two 3.3.0 candidates. The backup archive format remains version 1.

## Validation boundary

The earlier development review marked 3.3.0 **not ready for publication**
while native builds and release authorization were pending. This record
describes the subsequent approved package set; the PR and release page record
the separate publication checks.

All five native builders completed their dependency, OCR probe, package and
smoke checks. Broader packaged OCR, Study/Exam persistence and backup/restore
checks ran on Fedora with synthetic data. The additional Ubuntu 24.04 harness
was canceled; it is not a native Ubuntu acceptance result. The source audit
and CI do not prove the absence of defects or full accessibility conformance.
No owner data, production deployment or additional package build is part of
this release execution.
