# DLMS 3.3.2 RC1 and Desktop 3.3.2 Preview 1

**Published prereleases; neither is stable.** Existing 3.3.1 releases
and historical records remain available. All current application binaries report
`3.3.2 RC1`; Windows Desktop uses numeric resource/installer version `3.3.2.0` while
retaining that human-readable label.

## What changes

This maintenance candidate accepts readable certificate PDFs with restrictions
or an empty opening password, while retaining locked/malformed/active-content
rejection and resource limits. It updates PDF/image dependencies (including
pypdf 6.21.4 and Pillow 13.0.0). The owner confirmed a real encrypted certificate
uploaded on the updated dev server; the agent did not inspect that document or
connect to production. That result does not qualify all certificate actions or
older servers. Server-mode handling comes from the configured server; use the
updated matching server for the fix.

Windows Desktop's packaging-only correction separates numeric OS metadata from
the RC display label. Candidate2 also removes an ambient ICU/tool-PATH collection
problem; candidate1 is rejected and excluded. No shared application behavior was
changed by that packaging patch. The full 390-case Firefox gate is already passed
at the pin and was not repeated for this collection/documentation work.

## Downloads and first use

Choose the Original archive for Fedora 44, Ubuntu 24.04, Ubuntu 26.04, Windows 11
x86_64 or Apple Silicon macOS. Extract and run its named executable, or open the
extracted `DLMS.app` on Mac. Original package READMEs now give the correct platform
context, with identical executable/app contents and updated archive checksums.

Desktop provides the shared Linux x86_64 AppImage, Windows candidate2 Setup.exe,
and Apple Silicon DMG. The optional managed Linux archive retains the established
Fedora launcher/profile contract; it is not an Ubuntu installer or an AppImage
profile replacement. No live profile directory should be shared between editions.
Back up before upgrade and keep the prior payload. No schema/persistence or
portable-format migration was added by this maintenance change.

Windows is unsigned, needs the documented .NET 4.8/protected machine WebView2
runtime, and its installer was compiled, not executed in this qualification.
Mac Desktop is ad hoc signed, not Developer-ID signed/notarized, and qualified on
macOS 26.6.2 arm64 only. Use only the OS-offered per-app approval for a trusted
download; do not remove quarantine or disable platform protections.

## Ubuntu 26.04 warnings

The app and local chooser worked despite reported GVFS/portal/GBM/EGL diagnostics.
The GVFS symbol warning fits newer host modules versus the bundled GLib 2.80;
portal registration can warn without desktop integration, and graphics can use a
fallback. These warnings are disclosed Preview limitations, not a failed app test
by themselves. Optional GVFS/network integration and accelerated performance are
not established. No global environment/security workaround is required by the
available evidence. Detailed assessment is retained in the review packet.
