# DLMS 3.2.1 release notes

Status: prepared for owner review on September 23, 2026; not a publication record.
Package availability is determined by the GitHub Releases page.

DLMS remains a local-first, single-user learning application. This release
target converges the work following 3.2.0:

- Storage Health shows categorized usage and free-space guidance. Backup creation
  checks restore compatibility before publishing a backup. Restore accepts ZIPs
  up to 1 GiB while retaining expanded-size, member, entry and compression-ratio
  safeguards; sufficient temporary space is still required.
- Content Pack management improves grouping, filtering, compact presentation and
  spacing. Parsing preview preserves manual repairs and validates pasted content
  through the existing publication boundary.
- Native Windows icon resources derive from the existing DLMS artwork. Actual
  Explorer/shortcut and macOS Finder/Dock acceptance remains a native release gate.
- Optional experimental AppImage tooling includes host browser-environment
  handling. It does not replace the six native packages or their server/headless
  use. Final AppImage compatibility is tied to the exact frozen artifact.
- The manual and task-focused tutorial material cover the current workflows;
  unpublished tutorial candidates retain their owner editorial-review status.

Back up existing data before upgrading. Keep the normal application data directory;
do not replace it with packaged files. No version-bump migration or automatic
data cleanup is introduced. See the [manual](../user-manual/README.md),
[release checklist](3.2.1-RELEASE-CHECKLIST.md) and
[readiness assessment](3.2.1-READINESS.md).

Historical [3.2.0 notes](3.2.0.md) and acceptance evidence remain unchanged.
