# DLMS 3.2.0

DLMS 3.2.0 brings a more connected workflow for importing learning material,
practicing, taking assessments, and deciding what to review next. It is a
local-first, privacy-oriented, single-user desktop application with a browser
interface. No cloud account or direct AI-provider API is required.

## Highlights

- **Learning Scope:** choose which folders inform Learning Intelligence,
  recommendations, and generated review. Excluded material remains saved and
  playable, with its history and schedules intact. Hiding a folder remains a
  separate Library browsing choice.
- **Generated Practice lifecycle:** distinguish generated sessions from source
  quizzes, keep source-question provenance, and explicitly close a Study session
  with **Finish Review**. Completed sessions remain playable under Completed
  Generated Practice and continue to contribute to the original learning records.
- **Review Schedule:** inspect due, overdue, upcoming, and unscheduled questions,
  choose a review batch, and search/filter the queue. Question-level scheduling
  and concept-level retention remain distinct.
- **Study and Exam workflows:** use untimed Study feedback or a configured Exam
  time limit. Exam correctness and explanations wait until completion; Pause
  freezes the countdown and obscures the assessment. Matching and Hotspot
  questions support richer interactions alongside single- and multiple-answer
  questions.
- **Copy Question:** copy the AI-ready prompt for supported Study choice
  questions without leaving the quiz or sending it to an external provider.
  Matching/Hotspot and Exam Mode do not expose this action.

## Bring in content, review it, and reuse it

PDF & Image Import brings together selectable-text PDFs, question and terminology
banks, local OCR for supported scans/screenshots, and **Review & Repair**.
CSV terminology lists can become matching practice. Extraction remains a draft
to verify, with uncertainty and incomplete answers visible before publication.
Native OCR packages include Tesseract and PDFium; ordinary users do not need to
install system Tesseract separately.

**Content Packs** validates and manages reusable packages and tracks their
generated quizzes. **Study Packs** is the learner-facing catalog for creating
quizzes from installed datasets. The Content Packs summary cards now keep labels,
values, and descriptions aligned at desktop and narrower widths.

**Portable Quiz Bundles** transfer eligible source quizzes and supported images
without personal learning history. Export selection and eligibility reporting are
clearer, including hidden source material and excluded generated/Mixed quizzes.
The current portable format supports choice and matching questions, not
interactive hotspots; use a full backup to preserve the complete workspace.

**Duplicate Review** helps compare overlapping source questions while excluding
generated practice copies. Inspect the source answers and open the original quiz
for editing; the comparison report itself makes no changes.

**Anki Tools** exports selected questions and recorded misses for continued study
in Anki. The same selection workflow supports printable three-by-five physical
flash cards. External AI remains an optional manual prompt-and-paste workflow.

Choose the archive for your system from the assets attached to this release.
The supported target matrix and final filenames are listed below. A target is
available only when its rebuilt, verified archive is attached; the source tree
or an earlier 3.2.0 binary is not evidence of a final package.

|---|---|
| Fedora 44 x86_64 | `DLMS-3.2.0-fedora44-x86_64.tar.gz` |
| Ubuntu 24.04 x86_64 | `DLMS-3.2.0-ubuntu24.04-x86_64.tar.gz` |

| macOS Apple Silicon arm64 | `DLMS-3.2.0-macos-arm64.zip` |

Each archive contains the native application, `README.txt`, and `sample_quiz.txt`.
Linux builds are distribution-specific. macOS exposes `DLMS.app` and both support
files directly at the ZIP root, with no wrapper folder. Intel macOS is not part
of this release matrix. Unsigned Windows/macOS downloads may require the normal
platform approval steps documented in the manual; macOS is not notarized.

Check the archive against the release's `SHA256SUMS.txt` before running it.
GitHub's automatic source archives are for source use, not ready-to-run desktop
packages.

## Upgrading and protecting your data

Before upgrading, use **Settings → Backup & Restore** to create a full backup
and keep it outside the active application-data directory. Stop the old DLMS
process with **Shutdown DLMS**, extract the new package, and launch the matching
native application. Persistent data lives outside the executable/package; do not
delete or reset that directory as part of an upgrade.

Use a full backup for quizzes, settings, and learning history. Portable Quiz
Bundles and Content Pack exports serve content exchange and do not replace that
backup. Older backups without Learning Scope settings restore with all folders
included. Keep the pre-upgrade backup if you need to return to an older version;
do not assume newer saved data can be opened unchanged by every older release.

DLMS runs locally by default. Optional external-AI use sends only what you choose
to copy/share with that provider. Advanced LAN/server mode is single-user and
has no user authentication; it is not a public multi-user cloud service.
