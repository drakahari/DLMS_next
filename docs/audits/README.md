# Engineering Audits

This directory contains curated summaries of significant AI-assisted engineering
reviews of DLMS. They record the scope, evidence, findings, disposition, and
limitations of each review without publishing raw agent transcripts or internal
reasoning.

These records are project-maintainer engineering artifacts. They are not
independent third-party audits, security certifications, compliance attestations,
endorsements, or guarantees.
