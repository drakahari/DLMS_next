Exam Mode and Study Mode

Exam Mode

Use Exam Mode when you want a timed, test-like attempt. Questions are presented for completion before the final result is reviewed.

Study Mode

Use Study Mode when immediate learning feedback matters. DLMS can show correctness, explanations, and supported teaching detail after a response.

Study Mode feedback

Correct and incorrect responses are visually distinguished. When source material contains an explanation, DLMS displays it as part of the learning feedback. Some imported question banks can also include per-choice explanations.

After an attempt

Completed attempts feed History and Analytics. Use History when you want to inspect a specific attempt and Analytics when you want a broader performance view. Anki Tools can export quiz or missed-question material for later review.
