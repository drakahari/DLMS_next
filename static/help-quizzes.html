Organize the Quiz Library with folders

Choose New Folder, enter a name, and choose Save. DLMS saves the name immediately, but shows folder sections only when they contain at least one quiz in the selected Visible, Hidden, or All view. A new empty folder therefore may not appear as a folder section yet; it remains available in each quiz card’s Move list. If the last quiz leaves a folder, that folder section disappears from the current view, but the saved folder remains available for reuse.

Uncategorized is the default for quizzes that have no other folder. It uses the same visibility rule, but it cannot be renamed or deleted. If you delete a custom folder, DLMS moves its quizzes to Uncategorized.

To move a quiz to a different folder, choose Move on its card, select the destination folder, and choose Save.
Drag a folder header to reorder the visible folder sections.
Drag a quiz card to reorder it inside its current folder.
Visual cues and limits: Select a folder header to collapse or expand it; ▼ means expanded and ▶ means collapsed. Drag-and-drop reorders items but does not transfer quizzes between folders—use Move for that. A folder can also disappear temporarily when the selected view or search has no matching quiz.

Exam Mode and Study Mode

Exam Mode

Use Exam Mode when you want a timed, test-like attempt. Questions are presented for completion before the final result is reviewed.

Study Mode

Use Study Mode when immediate learning feedback matters. DLMS can show correctness, explanations, and supported teaching detail after a response.

Study Mode feedback

Correct and incorrect responses are visually distinguished. When source material contains an explanation, DLMS displays it as part of the learning feedback. Some imported question banks can also include per-choice explanations.

Review This Question with AI

This button appears in Study Mode and helps you get outside explanation on the current question. DLMS builds a structured prompt from the question, answer choices, your selected answer, and any available explanation, then opens your configured AI provider workflow so you can continue the review there.

Use it when you want a concept explanation, a breakdown of why the correct answer is right, and a quick explanation of why the other choices are weaker. This tool is meant for learning support, not for timed Exam Mode attempts.

Mark for Anki

This button appears in Study Mode when you want to save the current question for later spaced repetition. Marking a question adds it to a temporary Study Mode selection list. After you finish reviewing the session, DLMS can export the marked items into an Anki package so you can continue practice outside the quiz.

Use this when you notice a weak area, a high-value fact pattern, or a question you want to revisit later. The marking is session-based until you complete the export.

Important: These learning-assist actions are part of Study Mode. Exam Mode is intended to stay closer to a traditional test experience, so immediate learning aids are not the focus there.

Drag & Drop matching

Matching quizzes now default to a drag-and-drop workspace. Mouse users can drag answer chips into targets. Touch and keyboard users can select an answer first and then select its target. The Dropdowns control keeps the original matching interface available as an accessible fallback. Both interaction modes use the same answers and grading.

After an attempt

Once an attempt is saved, DLMS gives you several ways to continue learning from it rather than treating the score as the end of the session.

History = specific attempts

Use History when you want to find one exact attempt by quiz, date, score, origin, or mode. From there, select Review to reopen the missed-question snapshot for that attempt.

Analytics = patterns over time

Use Analytics when you want the broader picture. It groups attempts by quiz and shows averages, best scores, pass rate, recent performance, and trend information so you can identify weak or improving areas.

Review = learn from what you missed

The Review page focuses on the questions you answered incorrectly in that saved attempt. Depending on question type, it can preserve your answer, the correct answer, explanations, matching details, or hotspot feedback such as your click and the correct target.

Follow-up study

From Review, you can continue remediation by selecting missed material for Anki export and, when enabled, using AI-assisted explanation tools. This lets you move from a low score to targeted practice instead of simply retaking the entire quiz.

Recommended loop: Take quiz → check History → Review missed questions → export difficult items to Anki or use AI explanation → return to targeted practice → use Analytics to see whether performance improves.
