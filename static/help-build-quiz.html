Text and paste parsing

Structured question text should include a question stem, labeled answer choices, and a correct-answer marker. Parsing settings can be adjusted under Settings when your source uses a different answer marker or needs cleanup.

Regex Cleanup: DLMS retains a dedicated regex reference for cleaning copied PDF/exam text before parsing. Open Regex Cleanup Help.

Image-based quiz creation

Build from Images supports ordinary image questions and hotspot-style practice. Image Study Editor is the companion tool for preparing image overlays and refining clickable regions without modifying the original source image.

Editing Study Mode explanations and concept tags

When you open a quiz from the Quiz Library and choose Edit, each question includes an optional Study Mode Explanation field. PDF & Image Import explanations are preserved here, and you can correct imported explanation text or add your own teaching explanation without re-importing the source PDF. Saving the quiz rebuilds the generated quiz data and preserves the edited explanation for Study Mode.

Each question also includes an optional Concepts / Tags field. Enter comma-separated topic labels such as IAM, authentication, least privilege. DLMS stores these labels independently from the question text so later learning-intelligence features can calculate topic performance and build targeted review sets without changing the quiz itself.

Tag consistently. Reuse the same concept name when questions test the same idea. DLMS treats concept names case-insensitively and removes duplicate labels on save.
