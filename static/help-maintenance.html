System Tools & Recovery

Use advanced maintenance deliberately, and make a backup before broad changes.

System Tools

Open Settings → System Tools for advanced content and page-maintenance actions. The primary tool, Rebuild All Quiz Pages, refreshes generated HTML quiz wrappers after an upgrade; it does not rewrite questions, answers, quiz IDs, or attempt history.

System Tools also provides a secondary route to Image Study Editor. Ordinary study, quiz creation, and Study Pack use do not require System Tools.

Back up before recovery work

Open Settings → Data & History to create a portable backup ZIP before upgrades, restores, resets, or major content changes. Keep any backup you need outside the DLMS data directory before choosing a permanent-removal action.

Restore validates the selected DLMS backup before replacing active data and offers a confirmation step. If a restore cannot complete safely, DLMS reports failure instead of presenting a partial success.

Choose the narrowest reset

Reset & Recovery labels what each reset removes and preserves. Read that page carefully: clearing history, resetting source content, resetting settings, restoring a backup, and permanently removing local DLMS data have different effects.
