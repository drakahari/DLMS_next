System Tools & Data Management

Use advanced maintenance deliberately, create backups before major changes, and choose the narrowest reset or removal action that solves the problem.

System Tools

Open Settings → System Tools for advanced content and page-maintenance actions. Rebuild All Quiz Pages is an occasional maintenance and recovery tool—not a routine update step. You normally do not need to run it after updating DLMS.

Use it when DLMS specifically instructs you to refresh generated quiz pages, when existing quiz pages look stale or inconsistent with the current quiz interface, or when their generated HTML or playable JSON needs to be refreshed or repaired.

The tool regenerates only derived HTML and playable JSON page files from canonical saved quiz data. It does not rewrite questions, answers, correctness, quiz or question IDs, concepts, Question Identity lineage, folders, source or provenance details, scores, attempt history, or learning events.

System Tools also provides a secondary route to Image Study Editor. Ordinary study, quiz creation, and Study Pack use do not require System Tools.

Backup & Restore

Open Settings → Backup & Restore when you want to create or restore a portable backup or review recent backups stored on this device.

Portable Backup

Durable Study sessions, marked questions, Exam Plans, certifications, renewal periods, training/credit links and uploaded evidence are included, together with saved visibility, card-count and sort choices. Browser-only recovery checkpoints are not stored in the server backup; resolve pending saves first.

Create & Download Backup creates a portable ZIP snapshot and downloads it. The snapshot includes persistent quizzes and generated runtime data, the database and attempt history, settings, installed Study/Content Packs, quiz assets and persistent logos, PDF & Image Import source banks, PDF and image-builder drafts, Law Study content, and saved backgrounds.

The Quiz Library’s Download Quiz Library Reference (TXT) action serves a different purpose: it creates a human-readable reference, not a restorable or importable library package. Export on an individual quiz creates a classic choice-question text representation; it does not preserve matching, image, or hotspot interaction. Use Quiz Bundles for rich quiz transfer, or this portable backup for migration to another DLMS installation or a full restore.

Temporary uploads, Content Pack staging, temporary logo previews, restore-operation files, database sidecars, and older backup ZIPs are excluded. This keeps the portable ZIP focused on persistent DLMS data instead of temporary work or copies of earlier backups.

Recent safety backups

DLMS lists up to five recent backup ZIPs found in its backup folder on the current device. This list can include manual backups and safety backups made before reset or restore work. A backup that matters should also be downloaded or copied to a safe location—preferably outside the DLMS data directory and, when appropriate, onto another device.

Restore from Backup

Restore replaces the profile; it does not merge. Changes since the snapshot can be lost throughout DLMS. Older backups without plans or certifications can restore those collections to empty. Validate and confirm only a backup you intend to use.

Restore is intentionally cautious. First select a DLMS portable-backup ZIP and choose Validate Backup & Continue. DLMS checks the archive and its persistent data before showing a review-and-confirmation page; active data has not been replaced at that point.

After confirmation, DLMS creates a pre-restore safety backup of the current data before applying the validated snapshot. If applying or finalizing the restore fails, DLMS attempts to return to that pre-restore state rather than reporting a partial success. Keep the original uploaded backup and any important safety backup until you have confirmed the restored installation behaves as expected.

Compatibility, rollback and backup storage

Current schema 12 adds durable Study-mistake composition passes, stores explicit choice order and keeps Planning deadline, user-recorded Renewal deadline and Expires separate. Compatible older backups can be upgraded; an older application must refuse an upgraded database. Replacing the binary alone does not undo the database upgrade.

To roll back, stop DLMS normally; preserve the upgraded profile/current backup separately; use the compatible older application with a separate supported data root and restore a verified pre-upgrade backup through its restore workflow. Verify the recovered records/documents. An older backup loses later changes. Never edit schema numbers.

Restore rejects unsafe archive paths, oversized/invalid content and unexpected SQLite programs before migration writes. Keep a rejected original intact; do not manually install it or remove its triggers to bypass validation. Failed restore can invoke journaled recovery, but recovery is not an unconditional guarantee.

Backups use collision-safe, non-replacing publication, so rapid or simultaneous successful requests preserve distinct snapshots. Storage must support hard links; otherwise creation fails safely while earlier backups remain. Keep important downloaded backups outside the data directory.

Reset & Remove

The control on Backup & Restore only opens the action page. Opening it performs no reset. Each destructive control has a confirmation; choose the narrowest action.

Choose the narrowest reset that solves the problem. The six scoped reset actions below create a safety backup before changing data. Clear Saved Results has no automatic backup. Permanent removal of the complete data directory is different: it creates no in-place backup and also removes backups stored inside that directory.

Persistent Exam Result Storage

Clear Saved Results from Database and Dashboard removes stored attempts, their saved answers, and missed-question/history records. The quizzes themselves remain available. Durable Study sessions/completions and Learning Intelligence evidence remain. This action creates no automatic safety backup.

History-only cleanup: use this action to clear saved scored/legacy results. Durable Study History and learning estimates are separate and remain. Deleted history cannot be recovered unless it exists in a backup.

Reset Learning Intelligence

Clears answer evidence and derived mastery, recommendation, diagnostic and review estimates. Factual Study sessions/completions and saved attempts remain. Retained Study history does not rebuild the cleared estimates. Old Study queues are invalidated; reload open Study tabs before resuming. A safety backup is created first.

Delete Study History

Deletes factual Study sessions, responses, completions, preserved legacy Study responses and Study learning evidence. Exam attempts/evidence, quizzes, settings and certifications remain. A safety backup is created first; old queued Study requests are rejected. A browser confirmation also sends the exact DELETE STUDY HISTORY confirmation for server validation.

Reset Quiz Library & Results

This also deletes durable Study sessions/responses and preserved legacy Study responses. Certification/training records and saved plans remain, though removed quiz targets become unavailable. This removes quiz database records, questions and choices, concept and learning-event records tied to those questions, attempts and missed-question history, the Quiz Library registry, generated quiz JSON/HTML, quiz asset buckets, and quiz logos.

It preserves reusable source content and configuration: installed Study/Content Packs, PDF & Image Import question and terminology banks, PDF and image-builder drafts, Law Study content, application settings and backgrounds, and existing backup archives.

Clear Imported / Source Content

This clears reusable import material without deleting quizzes that have already been generated. It removes non-protected installed Content Packs, PDF & Image Import source banks, PDF and image-builder drafts, temporary uploads, and import/staging content. Packs marked as protected are preserved.

Before a removable Content Pack is deleted, DLMS snapshots dependencies needed by existing generated quizzes into quiz-owned storage. That protection is intended to keep those quizzes independent of the removed source pack; it does not preserve the reusable pack or source bank itself.

Reset Application Settings

This returns appearance—including custom backgrounds—parsing options, AI Integration, navigation visibility, application lifecycle, and Quiz Library folder preferences to current DLMS defaults. It also resets Learning Scope so all folders become included. Quizzes keep their existing folder assignments; empty configured folders are removed and hidden-folder state is cleared. It does not delete quizzes, learning evidence, result history, Study/Content Packs, PDF & Image Import banks, Law Study content, or backup archives.

Reset DLMS to Fresh State

This broad reset also removes certifications, documents, training, renewal history, plans and marks. It removes essentially all active user/runtime data: quizzes and generated files, questions and database records, history, Study/Content Packs, PDF & Image Import banks, Law Study content, drafts and assets, and application settings. DLMS then recreates the empty/default folders, database, and configuration needed to continue running.

Existing backup ZIPs in the DLMS backup folder are deliberately preserved, including the safety backup created for this reset. The executable or source installation is not removed.

Remove DLMS Data from This Computer

This is the most destructive option. After the exact phrase REMOVE DLMS DATA is typed and the final confirmation is accepted, DLMS deletes its verified writable application-data directory and shuts down. Quizzes, history, settings, Study/Content Packs, PDF & Image Import banks, Law Study content, drafts, assets, caches, and every backup stored inside that directory may all be removed.

Copy backups out first: this action does not create an automatic recovery backup. Download or copy every backup you want to keep somewhere outside the DLMS data directory before continuing. The DLMS executable or source installation itself is not removed; launching it again creates a new empty data directory.

Successful quiz-library/fresh-state resets and permanent removal clear this browser’s quiz recovery records. Other reset operations can invalidate old Study queues. Do not clear browser storage to fix a save failure. A failed scoped reset may have applied some changes; its safety backup is a recovery point, not automatic rollback. Preserve errors and recovery files.
