System Tools & Data Management

Use advanced maintenance deliberately, create backups before major changes, and choose the narrowest reset or removal action that solves the problem.

System Tools

Open Settings → System Tools for advanced content and page-maintenance actions. The primary tool, Rebuild All Quiz Pages, refreshes generated HTML quiz wrappers after an upgrade; it does not rewrite questions, answers, quiz IDs, or attempt history.

System Tools also provides a secondary route to Image Study Editor. Ordinary study, quiz creation, and Study Pack use do not require System Tools.

Backup & Restore

Open Settings → Backup & Restore when you want to create or restore a portable backup or review recent backups stored on this device.

Portable Backup

Create & Download Backup creates a portable ZIP snapshot and downloads it. The snapshot includes persistent quizzes and generated runtime data, the database and attempt history, settings, installed Study/Content Packs, quiz assets and persistent logos, Smart PDF source banks, PDF and image-builder drafts, Law Study content, and saved backgrounds.

The Quiz Library’s Download Quiz Library Reference (TXT) action serves a different purpose: it creates a human-readable reference, not a restorable or importable library package. Use Export on an individual quiz for an import-friendly classic MCQ text file. Use this portable backup for migration to another DLMS installation or a full restore.

Temporary uploads, Content Pack staging, temporary logo previews, restore-operation files, database sidecars, and older backup ZIPs are excluded. This keeps the portable ZIP focused on persistent DLMS data instead of temporary work or copies of earlier backups.

Recent safety backups

DLMS lists up to five recent backup ZIPs found in its backup folder on the current device. This list can include manual backups and safety backups made before reset or restore work. A backup that matters should also be downloaded or copied to a safe location—preferably outside the DLMS data directory and, when appropriate, onto another device.

Restore from Backup

Restore is intentionally cautious. First select a DLMS portable-backup ZIP and choose Validate Backup & Continue. DLMS checks the archive and its persistent data before showing a review-and-confirmation page; active data has not been replaced at that point.

After confirmation, DLMS creates a pre-restore safety backup of the current data before applying the validated snapshot. If applying or finalizing the restore fails, DLMS attempts to return to that pre-restore state rather than reporting a partial success. Keep the original uploaded backup and any important safety backup until you have confirmed the restored installation behaves as expected.

Reset & Remove

Choose the narrowest reset that solves the problem. The first four reset actions create a safety backup before changing data. Permanent removal of the complete data directory is different: it creates no in-place backup and also removes backups stored inside that directory.

Persistent Exam Result Storage

Clear Saved Results from Database and Dashboard removes stored attempts, their saved answers, and missed-question/history records. The quizzes themselves remain available in the Quiz Library.

History-only cleanup: use this action when you want to start performance history over without resetting quizzes, Study Packs, settings, or other content. Deleted history cannot be recovered unless it exists in a backup.

Reset Quiz Library & Results

This removes quiz database records, questions and choices, concept and learning-event records tied to those questions, attempts and missed-question history, the Quiz Library registry, generated quiz JSON/HTML, quiz asset buckets, and quiz logos.

It preserves reusable source content and configuration: installed Study/Content Packs, Smart PDF question and terminology banks, PDF and image-builder drafts, Law Study content, application settings and backgrounds, and existing backup archives.

Clear Imported / Source Content

This clears reusable import material without deleting quizzes that have already been generated. It removes non-protected installed Content Packs, Smart PDF source banks, PDF and image-builder drafts, temporary uploads, and import/staging content. Packs marked as protected are preserved.

Before a removable Content Pack is deleted, DLMS snapshots dependencies needed by existing generated quizzes into quiz-owned storage. That protection is intended to keep those quizzes independent of the removed source pack; it does not preserve the reusable pack or source bank itself.

Reset Application Settings

This returns appearance—including custom backgrounds—parsing options, AI integration, navigation visibility, and other portal settings to current DLMS defaults. It does not delete quizzes, result history, Study/Content Packs, Smart PDF banks, Law Study content, or backup archives.

Reset DLMS to Fresh State

This broad reset removes essentially all active user/runtime data: quizzes and generated files, questions and database records, history, Study/Content Packs, Smart PDF banks, Law Study content, drafts and assets, and application settings. DLMS then recreates the empty/default folders, database, and configuration needed to continue running.

Existing backup ZIPs in the DLMS backup folder are deliberately preserved, including the safety backup created for this reset. The executable or source installation is not removed.

Remove DLMS Data from This Computer

This is the most destructive option. After the exact phrase REMOVE DLMS DATA is typed and the final confirmation is accepted, DLMS deletes its verified writable application-data directory and shuts down. Quizzes, history, settings, Study/Content Packs, Smart PDF banks, Law Study content, drafts, assets, caches, and every backup stored inside that directory may all be removed.

Copy backups out first: this action does not create an automatic recovery backup. Download or copy every backup you want to keep somewhere outside the DLMS data directory before continuing. The DLMS executable or source installation itself is not removed; launching it again creates a new empty data directory.
