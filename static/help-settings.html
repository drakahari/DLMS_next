Settings & Personalization

Change presentation and workflow preferences without changing your study data.

Choose a color theme

Open Settings → Appearance to change DLMS’s colors. Theme selection is manual and works on supported DLMS hosts without installing Omarchy. Automatic matching to your desktop theme is not currently implemented.

Through Appearance settings

  1. Open Appearance and find Color theme.
  2. Choose a name from the grouped selector. Changing the selection does not apply it yet.
  3. Select Save Appearance. The page returns with Appearance settings saved. and the new theme.

This form also saves the dashboard title and background choices shown on that page. It does not change parsing, AI, content or history settings.

The screenshots use Light as an example. Select an image to enlarge it; press Escape to close the viewer.

Through the sidebar

  1. Find Theme near the bottom of the sidebar. On a narrow screen, use Toggle navigation to open the sidebar first.
  2. Choose a theme. The sidebar saves it immediately and reloads the current page after a successful save; no separate Save button is needed.

Both controls save the same application preference. It survives closing and restarting DLMS and applies to pages served by that DLMS instance, including other browsers using it. Already-open tabs keep their loaded colors until you reload or navigate in them.

What changes with a theme?

The theme changes shared interface colors: text, links, panels, controls, focus, selection, feedback and charts. Ethereal also has its established font and presentation choices. Themes do not change questions, answers, grading, content, history or Learning Intelligence.

Existing and newly generated quiz pages using DLMS’s shared CSS receive the selected theme when loaded; you do not need to rebuild those quizzes. Older self-contained quiz HTML with embedded styles may keep its original colors. A theme cannot recolor educational images, and printed output keeps its existing styling.

You can also set a dashboard title and background in Appearance. Theme selection does not install or change desktop wallpapers. Opaque surfaces in the new Omarchy palettes and adapted Ethereal keep text separate from uploaded background pixels.

Choose for comfortable reading

  • Try a light or dark choice in your usual lighting. Check question text, explanations, helper text and form fields before settling on a theme. If reading is tiring, try another choice or increase browser zoom.
  • Use Tab and Shift + Tab to move between controls and links. Look for the visible focus outline. Arrow keys move within the theme selector; native selection keys can vary by browser and operating system.
  • Read answer labels, explanations, scores and icons as well as their colors. A monochrome palette still uses distinct educational feedback colors; color alone does not establish correctness. Chart legends identify categories.

The palettes include web readability adjustments, but contrast checks alone do not establish full accessibility conformance. The five original DLMS choices retain their existing appearance, including known contrast limits on some Study/Exam selection buttons.

If the theme looks unchanged

  • Only changed the Appearance selector? Select Save Appearance and look for the saved message. A selected option alone is not a saved change.
  • An older tab still has the old colors? Reload that tab or navigate to another DLMS page. Make sure it is connected to the same DLMS instance.
  • Only an old quiz looks different? It may use self-contained HTML with embedded styles. Check the Dashboard or Appearance to confirm the current theme.
  • A saved theme value is unsupported or missing? DLMS displays Purple & Gold, the default. Reading that value does not rewrite the saved preference. Choose a supported theme and save it through either control to replace the unsupported value.
  • A save failed? The previous saved choice remains. Appearance shows a save error; the sidebar restores its prior selection and shows DLMS could not change the theme. Retry the choice. If the sidebar shows Themes unavailable, use its Open Appearance settings link or open Appearance here. If saving keeps failing, check access to the DLMS data folder and available disk space.

Layout & navigation

Study History and Exam History are independent dashboard shortcuts. When the new Study History choice has not been saved yet, it inherits your previous History choice. Thereafter either can be shown alone. Study next & Continue studying, Recent quiz activity and Results overview retain their separate panel preferences. Settings remains in the sidebar when every optional dashboard card is hidden.

Open Settings → Layout & navigation to choose where study areas appear and which dashboard cards you see. The sidebar’s Customize navigation link opens Study areas; Dashboard panels on this same page contains the dashboard choices. Older Navigation and Dashboard settings bookmarks redirect here.

Choose dashboard and sidebar visibility independently

  1. In Study areas, find IT Study, Law Study or Medical Study.
  2. Set Show on dashboard for its dashboard shortcut and Show in sidebar for its sidebar link. Choose either location, both, or neither. For example, you can keep Law Study in the sidebar while hiding its dashboard shortcut; neither checkbox changes the other.
  3. Use Hide from both to uncheck both boxes for that area. This updates the form only; select Save layout & navigation to apply it.

Other Studies has only Show in sidebar; it has no dashboard card. The Medical Study dashboard shortcut still requires an installed medical content pack. Its workspace and sidebar link remain available without that pack.

Choose other dashboard cards

Use Dashboard panels for the main panels and Dashboard quick access for the remaining shortcuts. These controls affect the dashboard only. Recent quiz activity controls its latest Study/Exam summaries together; the full histories stay on their History pages.

Select Save layout & navigation to save all dashboard and sidebar choices on the form. Look for Layout & navigation settings saved. Settings remains in the sidebar even if all optional dashboard content is hidden. Open Layout & navigation there to re-enable cards or restore dashboard defaults.

Restore only the defaults you want

  • Restore dashboard defaults immediately resets every dashboard visibility choice to visible, including study-area dashboard shortcuts. It preserves the saved sidebar choices.
  • Restore sidebar defaults immediately resets IT Study, Law Study, Medical Study and Other Studies to visible in the sidebar. It preserves the saved dashboard choices.

Neither Restore button changes unrelated settings. Restored cards still follow their content availability rules. Restore does not save unsaved checkbox edits in either group; the page reloads with the restored group and the other group’s saved choices. Save any edits you want to keep before using Restore.

Visibility only: hiding a card or sidebar link does not delete content, progress or history, disable direct URLs, or change Learning Scope. Re-enable its checkbox and save to show it again.

AI and parsing

AI Integration configures optional providers and editable prompt templates for supported workflows. DLMS works without an AI provider. Parsing changes how future copied/uploaded text is interpreted; it does not rewrite existing quizzes.

Backup, reset, and removal

Use Backup & Restore to create a portable backup or validate and restore an existing backup. Use Reset & Remove to clear persistent exam results, run a scoped reset, or remove DLMS data after reviewing what each action preserves and removes.

Before a major change: download a backup and keep it outside the DLMS data directory if you need an independent recovery copy.

System Tools

System Tools contains advanced operational actions such as rebuilding generated quiz pages and opening Image Study Editor. It is not a required part of ordinary study or quiz creation.
