Settings categories

Settings separates configuration into focused pages so application behavior can be changed without editing files by hand.

Appearance

Use Appearance for portal/title and visual preferences exposed by the current build.

AI integration

AI Integration configures the optional AI helper/provider settings used by supported study workflows. It also exposes editable prompt templates for missed-question explanations, general Study Pack generation, the Medical Study Pack safety addendum, and Law Study. Each template can be restored to its DLMS default. Local/custom configurations depend on the endpoint URL and model settings you provide; the application does not require an AI provider for ordinary quiz operation.

Parsing

Parsing settings control how copied/uploaded question text is interpreted. Use these only when your source format differs from the defaults; changing parser settings can affect future imports but does not rewrite already generated quizzes.

Data safety & history

The Data & History page now combines portable backup/restore with the existing saved-attempt history controls.

  • Create & Download Backup builds one portable ZIP containing persistent DLMS runtime data such as quizzes, the database/history, settings, Study/Content Packs, Smart PDF banks, drafts, Law Study content, quiz-owned assets, backgrounds, and persistent logos.
  • Temporary upload/staging files, temporary logo previews, and older backup archives are intentionally excluded from a new backup.
  • Restore from Backup validates the ZIP before changing data. DLMS checks archive integrity, paths, symlinks, duplicates, schema compatibility, and expansion limits, then shows a confirmation screen.
  • Immediately before applying a restore, DLMS creates a pre-restore safety backup of the current data. If applying the requested snapshot fails, DLMS attempts an automatic rollback to that pre-restore snapshot.
  • The existing history-clear control remains scoped to attempts, attempt answers, and missed-question history; quizzes remain available.
Recommended: create a portable backup before upgrades, large content changes, reset operations, or moving DLMS to another computer.

Content Packs

The Settings content area provides entry points/information for content-pack behavior, while the dedicated Content Packs page performs operational management.

Maintenance settings

The Settings maintenance category provides configuration/entry points related to maintenance behavior; operational maintenance actions are documented separately under Maintenance & Recovery.

Reset & recovery

Reset & Recovery provides several scopes so you do not have to erase more data than necessary. Each reset creates a safety backup first. The separate permanent-removal action deletes the backup directory too, so it requires typed confirmation and does not create an in-place recovery backup.

Themes

Settings → Appearance provides Dark, Light, and Purple & Gold themes. A compact sidebar chooser is also available for quick switching. Theme changes affect presentation only; quizzes, grading, learning data, and content are unchanged.
