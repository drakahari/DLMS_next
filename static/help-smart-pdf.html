What Smart PDF does

Smart PDF Import is a separate, additive importer for selectable-text PDFs. It recognizes two structured source types: question banks and glossary/terminology. It does not perform OCR, and it deliberately flags ambiguous material instead of guessing.

Question-bank PDFs

Open Build Quiz → PDF Import & Banks. Choose a PDF and leave Content type on Auto-detect unless the source has an unusual layout.
Analyze the PDF. DLMS detects question boundaries, choices, explicit correct-answer markers, explanations, and cross-page questions.
Review & Repair. Complete items are ready; Review items need attention; Incomplete items must be repaired or excluded before the bank can be saved.
Save the reviewed source bank. The original PDF does not need to be reparsed each time you want a new practice quiz.
Open the saved bank and choose Random, Unused, Sequential, Range, or All active questions to generate a manageable quiz.

Glossary / terminology PDFs

For PDFs that preserve formatting, DLMS can use font/style information to distinguish glossary terms from definition prose. When reliable style information is unavailable, it falls back to the deterministic heuristic parser.

Import the PDF and use Auto-detect or explicitly choose Glossary / terminology.
Review term/definition pairs. Exclude source artifacts instead of inventing missing definitions.
Save the Terminology Bank. The complete reviewed bank remains intact.
Generate Matching or Multiple Choice practice from Random, Unused, Sequential, Range, or All active terms.
Choose Term → Definition or Definition → Term when the practice type supports direction.

Managing PDF source banks

The Smart PDF landing page stores Question Banks and Terminology Banks in separate collapsible sections. Use Expand All / Collapse All when collections become long. Enable Manage Banks when you need deletion controls.

Deleting a source bank: deletion removes the reusable source-bank JSON. It is designed to leave already generated quizzes available.

Runtime storage is under the DLMS application-data directory in pdf_question_banks/ and pdf_terminology_banks/.

Current PDF limitations

  • Selectable text is required; OCR is not performed.
  • The importer intentionally targets structured question-bank and glossary layouts, not arbitrary textbook/chapter interpretation.
  • Question prompts that reference missing exhibits, diagrams, code, or output can be marked Review rather than falsely treated as complete.
  • The current upload limit is 64 MB; practical performance also depends on the amount and complexity of extracted text.
