Content Pack management

Content Packs are installed folders containing a manifest plus declared datasets/assets. DLMS independently validates installed and staged packs rather than trusting metadata at face value.

What you can manage

ActionPurpose
ImportStage a ZIP outside the live pack folder, inspect it for unsafe paths/symlinks/size limits, validate the manifest and datasets, then explicitly install.
DetailsView independent validation checks, warnings, errors, dataset counts, source metadata, and pack status.
ExportCreate a ZIP that preserves the pack's top-level folder so the same pack can be moved or archived.
DeleteRemove an installed source pack. DLMS protects generated quiz image dependencies by snapshotting pack assets into quiz-owned storage where needed.
A pack can be structurally valid yet fail runtime discovery if another installed folder uses the same pack ID. Details reports that condition instead of silently hiding it.

Image Study Editor

The Image Study Editor prepares images and clickable hotspot regions. Prep edits are stored as non-destructive overlays in content JSON; the original source image is not modified. Hotspot tools support loading existing shapes, undoing points, clearing/testing a shape, and saving the region.
