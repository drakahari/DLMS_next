Content Packs & Images

Manage externally created study content and prepare image-based study material.

Import a Content Pack ZIP

Open Content Packs and choose Import.
Select a DLMS Content Pack ZIP. DLMS stages and validates it before changing installed content.
Read the validation results. Fix blocking errors; review warning-only packs and explicitly confirm before installing.
After installation, open Study Packs to use learner-facing activities, or stay in Content Packs to inspect, export, or manage the pack.

Manual Content Pack import remains useful for externally created packs. AI Builder ZIP returns use the same validation and installation safeguards without requiring this separate navigation step.

Manage installed packs

Use Details to inspect validation and dataset information, Export to make a portable pack ZIP, and Delete only when you no longer need the source pack. Generated quizzes remain separate practice copies; DLMS protects required quiz-owned image dependencies when appropriate.

Image Study Editor

Open Image Study Editor directly from the sidebar or System Tools to prepare images, add non-destructive overlays, define circle or polygon hotspot regions, test them, and save the metadata into installed content.
