History: Attempts & Review

History is the chronological record of completed quiz attempts. It is the place to answer questions such as What did I take?, When did I take it?, What score did I receive?, and Which attempt do I want to review?

What the History page shows

FieldMeaning
AttemptsTotal number of saved quiz attempts.
AverageAverage percentage across all saved attempts.
Best ScoreHighest percentage recorded in saved history.
OriginWhere the quiz came from, such as Quiz, IT, Medical, Study Pack, or Law.
ScoreThe percentage and raw correct/total result for that specific attempt.
DateWhen the attempt was completed.
ModeThe quiz mode used for the recorded attempt, such as Exam.
ReviewOpens the saved missed-question review for that exact attempt.

The filter buttons above the table let you narrow History by origin without deleting or changing any saved attempts.

Use History when you care about one specific sitting. Analytics is better for patterns across multiple attempts.

Review missed questions

Select Review from History—or from the latest-attempt link in Analytics—to reopen the missed-question snapshot saved for that attempt. Review is intended for remediation: it shows what was missed and preserves enough context to study the mistake later.

What Review can preserve

  • Question text and the answer snapshot associated with the attempt.
  • The learner's selected answer and the correct answer for ordinary questions.
  • Matching-question pair data when the missed item is a matching question.
  • For image hotspots, the original image, the learner's selected location, the correct target, the target label, explanation, and available source/verification metadata.
  • Tools for turning missed material into follow-up study, including Anki export and AI-assisted explanation controls when those features are enabled.
History → Review → Anki is a useful remediation workflow: locate a weak attempt, inspect what was missed, then export selected missed questions for spaced repetition.

Analytics: Progress & Performance

Analytics summarizes saved attempts across quizzes. Unlike History, which lists individual attempts in time order, Analytics groups attempts by quiz and calculates performance indicators so you can see where results are improving, declining, or remaining steady.

Summary cards

MetricHow DLMS calculates it
Total AttemptsNumber of saved attempts currently available to Analytics.
Quizzes StudiedNumber of distinct quiz titles represented by those attempts.
Average ScoreMean percentage across all saved attempts, rounded to a whole percent.
Best ScoreHighest saved attempt percentage.

Quiz Performance table

ColumnMeaning
AttemptsHow many saved attempts exist for that quiz.
AverageAverage percentage across that quiz's saved attempts.
BestHighest percentage achieved for that quiz.
Pass RatePercentage of attempts scoring at least 75%.
TrendCompares the two most recent attempts: higher = Improving, lower = Down, equal = Steady. With fewer than two attempts, DLMS shows Not enough data.
LatestThe newest attempt's score and completion date.
ReviewOpens the newest attempt for that quiz when an attempt ID is available.

Score indicators are also visually grouped: 80% and above uses the positive score treatment, 60–79% uses the warning treatment, and scores below 60% use the lower-score treatment. These colors are display cues; the Analytics pass-rate calculation itself uses the 75% threshold.

Use Analytics for patterns. If a quiz shows a downward trend or a weak pass rate, use Review to inspect the latest misses and then return to targeted practice.

Learning-event foundation

DLMS now records a separate learning-event stream for Study Mode answer interactions and completed Exam Mode responses. These events are stored alongside existing History rather than replacing it. When a question has Concepts / Tags, the event can be associated with those concepts through the question record.

The current History and Analytics screens continue to behave as before. Topic Accuracy, Mastery, and Weak-Area views are now available in the Learning Intelligence workspace.

Learning Intelligence

The Learning Intelligence workspace builds on optional Concepts / Tags and recorded learning events. It shows topic-level accuracy, an explainable mastery score, and weak-area detection without replacing History or the existing Analytics page.

Evidence safeguards: Study Mode interactions are de-duplicated by question and study session, Exam Mode uses one response per question/attempt, and a topic needs at least three responses before DLMS can classify it as a weak area.

Smart Review: when weak areas exist, DLMS can generate a targeted review quiz from existing tagged questions associated with those weak concepts. The original question content is reused; DLMS does not invent new questions for this workflow.

Learning Profile: summarizes overall accuracy/mastery, activity, strongest topics, weak areas, and a recommended next study action.

Data retention

History and quiz data live in the writable DLMS application-data directory, separate from the executable. Settings includes data/history controls, while Maintenance and backup procedures should be used before major upgrades or destructive cleanup.
