Anki & Printable Cards

Reuse selected quiz, missed-question, and Law Study material for later review.

Export to Anki

Open Anki Tools to build a Custom Deck or use Law Study Anki. Select only the quiz questions, missed questions, or Law flashcards you want, preview the deck, then export the APKG file and import it into Anki. History Review exports use the source quiz title with “Missed Questions” so the downloaded filename and imported deck are easy to recognize.

Print physical flashcards

Open Anki Tools → Custom Deck.
Select one or more quiz questions, missed questions, and/or Law Study flashcards.
Choose the Avery 5388 printable option and select long-edge or short-edge duplex flipping.
Select Open Avery Print Layout. DLMS opens alternating front and matching back sheets in a new printable view.
Print one duplex test sheet first. Confirm orientation, then use the printer’s card-stock/index-card setting when available.

Avery 5388 uses 3 × 5 inch cards, with three cards per US Letter sheet. Long-edge flip keeps back cards in the same order; short-edge flip reverses back order for printers that require it.

Limit: very long card content is compacted to fit. If a card is hard to read, print fewer/shorter selected cards or use an Anki export instead.

Law Study cards

Law Study Anki uses flashcards from saved Case Reviews. It remains separate from the general Custom Deck workflow, but selected Law cards can also be included in printable-card selections.
